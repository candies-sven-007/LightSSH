LightSSH 1.3  —  简洁的 SSH 客户端 / A clean SSH client

【中文】
1. 解压整个文件夹，双击 LightSSH.exe 运行（无需安装）。
   首次运行如出现 Windows SmartScreen 提示，点「更多信息」→「仍要运行」。
2. 「新建主机」添加服务器，支持密码或私钥；密码用 Windows 系统加密保存。主机可分组、复制、右键管理。
3. 点主机即连接，支持多标签；主页顶部输入 user@host:端口 回车可快速连接。
4. 「片段」：保存常用命令；在终端右上角闪电图标里点一下就执行（按住 Shift 只粘贴不执行）。
5. 终端右上角文件图标打开 SFTP：双击进入目录或下载，右键上传、重命名、删除、复制路径、在终端中打开，支持拖放上传。
6. 左下角「设置」：背景（随时间 / 白天 / 黄昏 / 夜晚）、语言、字号、字体、光标、选中即复制。

快捷键：Ctrl+F 查找 · Ctrl+Shift+C/V 复制粘贴 · 右键菜单 · Ctrl+Tab 切换标签 · Ctrl+Shift+W 关闭标签
        Ctrl+Shift+T 回主页 · Ctrl +/- 字号，Ctrl+0 还原 · 断开后按 Enter 重连
数据保存位置：%APPDATA%\LightSSH

[English]
1. Unzip the whole folder and run LightSSH.exe (no install). If SmartScreen appears: "More info" -> "Run anyway".
2. "New Host" adds a server (password or private key, encrypted with Windows DPAPI). Group, duplicate, right-click to manage.
3. Click a host to connect; multiple tabs. Type user@host:port in Quick connect on the home page.
4. Snippets: save frequent commands; run them from the lightning icon in the terminal (hold Shift to paste only).
5. The folder icon in the terminal opens SFTP: double-click to open/download, right-click for upload, rename, delete, copy path, open in terminal; drag & drop upload.
6. Settings (bottom-left): background (auto by time / day / dusk / night), language, font size, font, cursor, copy on select.

Shortcuts: Ctrl+F find · Ctrl+Shift+C/V copy/paste · Ctrl+Tab switch tabs · Ctrl+Shift+W close tab
           Ctrl+Shift+T home · Ctrl +/- font, Ctrl+0 reset · press Enter to reconnect
Data folder: %APPDATA%\LightSSH
